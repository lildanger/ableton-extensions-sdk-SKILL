# Danjuan Ableton Extension 助手

你好！如果你是一名想要定制 Ableton Live 插件，但完全不懂写代码的音乐人，那么这个工具正是为你准备的。

这是一个专门配合 AI 助手使用的“大脑指南”（SKILL.md）。当你的 AI 助手加载了这个指南后，它就变成了一个绝对专业的插件开发代工。你只需要用平时做音乐的语言说出想要什么功能，它就能全自动帮你搞定所有复杂的写代码和打包工作。

## 你能用它做什么

你可以让 AI 帮你制作各种提升音乐制作效率的工具。比如：
- 右键点击一段音频剪辑，一键删掉里面所有的静音空白部分。
- 右键选中几条轨道，一键把它们批量重命名或上色。
- 给选中的片段一键切换特定的变形模式（Warp Mode）。
- 弹出一个输入框，让你输入数值，然后让插件自动去处理。

所有的想法，你只需要讲给 AI 听就好，不需要懂任何诸如“环境变量、代码编译、底层逻辑”的技术词汇。

## 怎么开始使用

1. 准备材料
确保你的电脑里有一个名称带有 "extensions-sdk" 的文件夹（或压缩包）。这是 Ableton 官方提供的插件开发包。请把它和本工具放在同一个工作目录中。

2. 告诉 AI 你的想法
对你的 AI 助手说出你的需求。例如：“帮我做一个插件，当我在排列视图（Arrangement View）右键音频轨道时，能出现一个菜单，点击后自动对齐所有的音频块。”

3. 拿到成品
AI 收到你的需求后，会在后台默默把所有繁琐的代码写好并打包。很快，它就会交给你一个后缀名为 ".ablx" 的安装文件。

4. 安装插件
打开你的 Ableton Live，进入偏好设置（Preferences）里的 Extensions 页面，确保开启了开发者模式（Developer Mode）。然后，直接把刚才拿到的 ".ablx" 文件拖拽进这个设置页面里。大功告成！现在你就可以在 Live 里面用你自己定制的专属插件了。

## 包含哪些文件

- SKILL.md: 这是专门写给 AI 助手看的“操作手册”，里面包含了所有的底层防错规则。请不要随意修改它，以免你的 AI 助手“忘记”怎么做插件。
