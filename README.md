# Danjuan Ableton 扩展制作 SKILL

想给你的 Ableton Live 加点私人定制的小工具，但又完全不会敲代码？这套专为大模型（比如 ChatGPT, Claude, 豆包, Kimi 等）准备的系统提示词（Prompt/Skill），就是为你量身定做的。

简单来说，你只要把 `SKILL.md` 喂给你的 AI 助手，它就会立刻变成一个极度专业的 Ableton 插件开发“外包”。你只需用平时干活的行话（比如：音轨、Clip、排列视图）告诉它你要什么，它就能全自动帮你把代码写好并打包，最后交给你一个直接拖拽就能用的插件。

## 这玩意儿能用来干嘛？

编曲或混音时经常会遇到繁琐的重复劳动，现在你可以让 AI 帮你做个右键小工具一键搞定。比如：
- 框选一段音频，右键一键删掉所有的静音部分。
- 右键选中多条轨道，一键批量重命名、按规律上色。
- 一键把选中的采样分轨全部切到 Complex Pro 模式。
- 做一个弹窗，让你输入数值批量调节音量门限。

所有的想法，你只要像平时聊天一样讲给 AI 听就行。至于什么“环境配置、代码编译、底层逻辑”，你统统不用管。

## 使用流程（只需 4 步）

1. **准备官方依赖包**
把 Ableton 官方提供的（名字带 `extensions-sdk` 的）文件夹或压缩包，和本工具放在同一个工作目录里。

2. **调教你的 AI**
把当前目录下的 `SKILL.md` 文件的内容完整发给你的 AI 助手（或者作为知识库/System Prompt 喂给它）。

3. **当甲方，提需求**
对 AI 提出你的需求，例如：“帮我做个插件，在 Arrangement（排列视图）右键音频轨道时，能出现一个菜单，点击后自动对齐所有的音频块。”

4. **一键提货**
AI 收到需求后，会在后台默默把所有繁琐的代码写好并编译。如果你电脑里连最基础的运行环境（比如 Node.js）都没有，它甚至会贴心地在后台全自动帮你装好。最后，它会交给你一个后缀名为 `.ablx` 的安装文件。

5. **安装到 Live**
打开 Ableton Live 的设置（Preferences），进入 Extensions 页面，把开发者模式（Developer Mode）打开。然后直接把拿到的 `.ablx` 文件拖进去。完事！你现在就能在 Live 里右键使用自己做的插件了。

## 包含文件

- `README.md`: 你现在看的这份快速入门指南。
